# cpp-learning

Mon parcours d'apprentissage du C++ : notes, exercices et mini-projets, organisés par thème.

Sources : un cours complet (~27h), « C++ tutorial for beginners » (Bro Code) et « Apprenez à programmer en C++ » (OpenClassrooms).
